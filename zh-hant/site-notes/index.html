網站說明

私隱與圖片使用

這個個人攝影檔案如何對待訪客資料及作品照片。

私隱

這是郭文棣的個人、非商業攝影檔案。網站沒有帳戶、表格或郵寄名單，也從不要求你提供姓名或電郵地址。

可選瀏覽統計

只有在你選擇「允許統計」後，網站才會載入 Google Analytics。選擇允許後，Google 會收到頁面網址（不含網址參數）、來源頁面網址、瀏覽器及裝置資料和你的 IP 位址，以及三項作品瀏覽動作：打開作品、篩選系列和切換語言。Google 可能設定其分析 Cookie。廣告功能及 Google 訊號均已關閉，Google 可能在加拿大以外處理這些資料。

如果你拒絕或未作選擇，網站不會向 Google 傳送任何資料。

你的選擇

你的選擇儲存在瀏覽器的本機儲存空間，名稱為「rickykwok.analytics-consent.v2」。你可隨時透過每頁底部的「瀏覽統計選擇」更改。選擇拒絕會停止日後的統計，並移除本網站可存取的 Google Analytics Cookie；你亦可在瀏覽器設定中清除 Cookie。

網站寄存

網頁經 Cloudflare 及 GitHub Pages 傳送，兩者會為傳送網頁及維護網站安全而處理 IP 位址。本網站本身不設定任何 Cookie。

圖片使用

所有照片版權屬郭文棣所有。除非照片所屬頁面另有說明，否則保留所有權利。本網站不授權複製或再使用。

少數照片以 CC BY-SA 4.0 發布；如適用，該照片所屬頁面會清楚列明，並以該頁條款為準。本網站不設任何許可申請程序。
