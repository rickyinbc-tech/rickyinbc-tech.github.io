网站说明

隐私与图片使用

这个个人摄影档案如何对待访客数据及作品照片。

隐私

这是郭文棣的个人、非商业摄影档案。网站没有账户、表格或邮寄名单，也从不要求你提供姓名或电子邮件地址。

可选浏览统计

只有在你选择“允许统计”后，网站才会加载 Google Analytics。选择允许后，Google 会收到页面网址（不含网址参数）、来源页面网址、浏览器及设备信息和你的 IP 地址，以及三项作品浏览动作：打开作品、筛选系列和切换语言。Google 可能设置其分析 Cookie。广告功能及 Google 信号均已关闭，Google 可能在加拿大以外处理这些数据。

如果你拒绝或未作选择，网站不会向 Google 发送任何数据。

你的选择

你的选择保存在浏览器的本地存储中，名称为“rickykwok.analytics-consent.v2”。你可随时通过每页底部的“浏览统计选择”更改。选择拒绝会停止日后的统计，并移除本网站可访问的 Google Analytics Cookie；你也可以在浏览器设置中清除 Cookie。

网站托管

网页经 Cloudflare 及 GitHub Pages 传送，两者会为传送网页及维护网站安全而处理 IP 地址。本网站本身不设置任何 Cookie。

图片使用

所有照片版权归郭文棣所有。除非照片所属页面另有说明，否则保留所有权利。本网站不授权复制或再使用。

少数照片以 CC BY-SA 4.0 发布；如适用，该照片所属页面会清楚列明，并以该页条款为准。本网站不设任何许可申请程序。
